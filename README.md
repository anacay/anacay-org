# anacay.org

One static page: the open, non-commercial work Anacay supports, and the hub that links the rest of the environment (anacay.com, Sentient Minds, LinkedIn). Today that's the Capacity Planning Practice (cpp.anacay.org). Add a list item to `public/index.html` when another seed is ready to be public.

No build step, no scripts, no tracking. Deploy with Wrangler from this folder (see `wrangler.jsonc`).
